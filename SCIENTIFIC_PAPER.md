# НАУЧНАЯ РАБОТА

## Разработка алгоритма интеллектуального анализа данных на основе математических моделей

---

## 1. ВВЕДЕНИЕ

Интеллектуальный анализ данных (Data Mining) представляет собой процесс обнаружения закономерностей в больших массивах данных с помощью методов машинного обучения, статистики и математического моделирования. В условиях экспоненциального роста объёмов данных, генерируемых современными системами, актуальность автоматизации процессов анализа и моделирования неуклонно возрастает.

Настоящий проект посвящён разработке автоматизированной системы, способной самостоятельно выбирать оптимальную математическую модель для прогнозирования на основе входного набора данных. Система реализует подход Automated Machine Learning (AutoML), при котором человек предоставляет данные, а алгоритм самостоятельно определяет тип задачи, проводит предобработку, обучает несколько моделей и выбирает лучшую.

## 2. АКТУАЛЬНОСТЬ

По данным International Data Corporation (IDC), объём данных в мире к 2025 году достигнет 175 зеттабайт. Традиционные методы анализа данных не способны эффективно обрабатывать такие объёмы. Автоматизированные системы машинного обучения позволяют:

- Ускорить процесс построения предиктивных моделей в 10-100 раз
- Снизить требования к квалификации специалиста
- Повторяемость экспериментов и воспроизводимость результатов
- Масштабирование анализа на множество датасетов

## 3. ПРОБЛЕМА

При построении модели машинного обучения необходимо решить множество взаимосвязанных задач:

1. **Выбор типа модели** — регрессия, классификация, кластеризация
2. **Предобработка данных** — обработка пропусков, кодирование категорий, масштабирование
3. **Подбор гиперпараметров** — глубина дерева, скорость обучения, количество деревьев
4. **Оценка качества** — выбор метрик, кросс-валидация
5. **Сравнение альтернатив** — объективное сравнение разных подходов

Каждая из этих задач требует экспертизы и занимает значительное время. Ручной подход неизбежно приводит к субъективности выбора и увеличению времени разработки.

## 4. ЦЕЛЬ

Разработать автоматизированную систему интеллектуального анализа данных, которая на основе входного набора данных самостоятельно определяет тип задачи, обучает несколько математических моделей, проводит их сравнительную оценку с использованием кросс-валидации и выбирает наиболее точную модель для прогнозирования.

Алгоритмы автоматического машинного обучения (AutoML) для задач регрессии и классификации, включая предобработку, обучение, кросс-валидацию и выбор модели.

## 9. ТЕОРЕТИЧЕСКАЯ ЧАСТЬ

### 9.1. Машинное обучение

Машинное обучение — это область искусственного интеллекта, которая занимается разработкой алгоритмов, способных учиться на данных и делать предсказания без явного программирования. Ключевые концепции:

- **Обучающая выборка** — набор данных, на котором модель учится
- **Признаки (features)** — входные переменные
- **Целевая переменная (target)** — то, что модель предсказывает
- **Обобщение** — способность модели работать на новых, ранее невиданных данных

### 9.2. Типы задач

**Регрессия** — предсказание непрерывной числовой переменной. Пример: предсказание оценки по часам учёбы.

**Классификация** — предсказание дискретной категории. Пример: определение, сдаст ли студент экзамен (0/1).

### 9.3. Предобработка данных

Качество модели напрямую зависит от качества входных данных. Ключевые этапы:

- **Обработка пропусков** — замена медианой (числовые) или модой (категориальные)
- **Кодирование категорий** — OneHot Encoding для номинальных переменных
- **Масштабирование** — StandardScaler (z-нормализация): x' = (x - μ) / σ

Использование Pipeline и ColumnTransformer гарантирует отсутствие data leakage — информация из тестовой выборки не попадает в процесс обучения.

## 10. МАТЕМАТИЧЕСКАЯ МОДЕЛЬ

### 10.1. Линейная регрессия

Модель линейной регрессии предполагает линейную зависимость между признаками и целевой переменной:

```
y = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

В матричной форме:

```
y = Xw + b
```

где:
- **y** — вектор целевой переменной (n×1)
- **X** — матрица признаков (n×m)
- **w** — вектор весов (m×1)
- **b** — смещение (scalar)

### 10.2. Метод наименьших квадратов

Оптимальные параметры w и b находятся минимизацией суммы квадратов ошибок:

```
L(w,b) = Σᵢ₌₁ⁿ (yᵢ - ŷᵢ)² = Σᵢ₌₁ⁿ (yᵢ - (Xᵢw + b))²
```

Аналитическое решение (Normal Equation):

```
w* = (XᵀX)⁻¹Xᵀy
```

Это решение является глобальным минимумом функции потерь и находится за одно вычисление.

### 10.3. Градиентный спуск

Альтернативный метод — итеративная оптимизация:

```
w(t+1) = w(t) - α · ∂L/∂w
b(t+1) = b(t) - α · ∂L/∂b
```

где α — скорость обучения, ∂L/∂w = -2/n · Xᵀ(y - Xw).

Градиентный спуск масштабируем для больших datasets, но требует настройки гиперпараметров (α, число итераций).

### 10.4. Полиномиальная регрессия

Расширение линейной модели добавлением полиномиальных признаков:

```
y = w₁x + w₂x² + w₃x³ + ... + b
```

Позволяет моделировать нелинейные зависимости, сохраняя линейность по параметрам.

### 10.5. Логистическая регрессия

Для задач классификации:

```
P(y=1|x) = σ(wᵀx + b) = 1 / (1 + e^(-(wᵀx+b)))
```

где σ — сигмоидная функция, converts lincom в вероятность.

## 12. ПРАКТИЧЕСКАЯ РЕАЛИЗАЦИЯ

Система реализована на Python с использованием следующих компонентов:

- **data_loader.py** — модуль загрузки CSV и анализа структуры данных
- **preprocessing.py** — автоматическая предобработка с Pipeline/ColumnTransformer
- **models.py** — определение набора моделей для регрессии и классификации
- **training.py** — обучение моделей с кросс-валидацией
- **evaluation.py** — оценка, эксперименты, переобучение, прогнозы
- **visualization.py** — построение графиков (4 типа)
- **custom_linear.py** — собственная реализация Linear Regression (Normal Equation + Gradient Descent)
- **pipeline.py** — неинтерактивное ядро: потоковое обучение, история тренировок, сводная статистика
- **dashboard_viz.py** — графики 01–07 в стиле печатного отчёта (динамика, счёт побед, кривая обучения)
- **server.py** — локальный Flask-сервер и REST API (SSE-поток событий обучения)
- **index.html** — веб-дашборд: разделы «Тренировка», «Статистика», «Как это работает», «Примеры»
- **extended_training.py** — расширенная тренировочная сессия (непрерывно ≥ 40 минут)
- **main.py** — CLI интерфейс

### Интерфейсы системы:

1. **Веб-дашборд** (`start.bat` → http://localhost:5000) — запуск тренировок с живым протоколом,
   полная статистика всех прогонов, методология, примеры использования и решённых задач
2. **CLI** (`main.py`) — интерактивное меню для отладки пайплайна
3. **HTTP API** — программный доступ к обучению, статистике и прогнозу (см. README.md)

### Ключевые технические решения:

1. **Pipeline** — гарантирует, что предобработка применяется корректно и нет data leakage
2. **ColumnTransformer** — позволяет по-разному обрабатывать числовые и категориальные признаки
3. **cross_val_score** — объективная оценка обобщающей способности модели
4. **joblib** — сохранение и загрузка обученных моделей

2. Random Forest показывает хорошие результаты, но уступает Polynomial Regression на данном простом датасете
3. Добавление данных наиболее эффективно для моделей с высокой вариативностью
