# Интеллектуальная система анализа данных (AutoML)

**Научный проект:** «Разработка алгоритма интеллектуального анализа данных на основе математических моделей»

Единый локальный дашборд (`start.bat` → `http://localhost:5000`), в котором собрано всё:
**тренировка алгоритма**, **вся статистика прогона за прогоном**, **раздел «как это работает»**
с математическим аппаратом и **раздел с примерами использования и решёнными задачами**.

---

## Что делает система

Пользователь даёт CSV — система сама:

1. **Загружает и анализирует** данные (строки, столбцы, типы, пропуски, статистика);
2. **Предобрабатывает**: пропуски → one-hot кодирование → масштабирование, всё внутри `Pipeline` (без утечки данных);
3. **Определяет тип задачи**: регрессия или классификация (можно переопределить вручную);
4. **Обучает несколько математических моделей** с k-fold кросс-валидацией;
5. **Сравнивает и выбирает лучшую** модель по среднему CV-показателю;
6. **Оценивает** лучшую модель на отложенном тесте (MAE / MSE / RMSE / R² или Accuracy / Precision / Recall / F1);
7. **Сохраняет пайплайн** (`models/best_model.pkl`) и выдаёт прогноз по новым данным;
8. **Ведёт полный протокол**: каждый прогон пишется в историю, вся статистика доступна в дашборде.

## Дашборд — 4 раздела (всё в одном сайте)

| Раздел | Содержание |
|--------|-----------|
| **01 · Тренировка** | выбор/загрузка датасета, карточка данных, параметры (цель, тип задачи, k-fold, доля теста), запуск обучения с живым SSE-протоколом и прогресс-баром, рейтинг моделей, тестовые метрики, **прогноз формой**, графики 01–04, 4 серии экспериментов, проверка собственной реализации LR |
| **02 · Статистика** | KPI по всем тренировкам (число прогонов, моделей, fold-проходов, суммарное время, лучший показатель), **статус расширенной сессии ≥ 40 минут в реальном времени**, графики динамики 05–07, средние показатели и победы моделей, полный журнал всех прогонов |
| **03 · Как это работает** | конвейер из 8 этапов, схема k-fold, математический аппарат (МНК, Normal Equation, градиентный спуск, полиномиальная и логистическая регрессия, R², F1), расшифровка метрик, каталог моделей |
| **04 · Примеры и задачи** | как запускать, примеры кода (Python-библиотека и HTTP API), **6 решённых задач с фактическими цифрами**, рекомендованный порядок работы для научной части |

Оформление — в стиле печатного служебного отчёта: приглушённая сине-оливково-песочная палитра,
шифровые линейки, анимации появления, счётчики, «печатающийся» заголовок, подсветка шагов конвейера.

## Расширенная тренировочная сессия (≥ 40 минут)

```bash
python extended_training.py     # Ctrl+C — корректное завершение
```

Сессия непрерывно обучает алгоритм **не менее 40 минут** по 5 фазам:

- **A** — реальные данные: все доли разбиения (70/30 … 95/5) × все k (3/5/7/10);
- **B** — синтетические датасеты 2 000–20 000 строк, 3–10 признаков, регрессия и классификация;
- **C** — перебор гиперпараметров Random Forest (`n_estimators` × `max_depth`);
- **D** — устойчивость результатов к `random_state`;
- **E** — кривые обучения (объём данных → качество).

Статус сессии (прогресс, число прогонов, лучший показатель, последние прогоны) виден в дашборде
в разделе **02.2 в реальном времени**; результаты пишутся в `results/extended_session.json`
и дописываются в общую историю тренировок.

## HTTP API

| Метод | Эндпоинт | Назначение |
|-------|----------|-----------|
| GET | `/api/datasets` | список датасетов |
| GET | `/api/describe?dataset=` | полное описание датасета |

| GET | `/api/stats` | сводная статистика всех тренировок |
| GET | `/api/history?limit=` | журнал прогонов |
| GET | `/api/session` | статус расширенной сессии |
| GET | `/api/predict-meta` | метаданные сохранённой модели |
| POST | `/api/predict` | прогноз сохранённой моделью |
| GET | `/api/custom-linear` | собственная LR vs sklearn |
| GET | `/api/system` | версии, источники кода, список документов |

     -H "Content-Type: application/json" \
     -d '{"dataset":"study_scores.csv","cv_folds":5,"test_size":0.2}'

## Фактические результаты

**Регрессия** (`study_scores.csv`, 62 строки, 1 признак):

| Модель | CV R² (mean) | CV R² (std) |
|--------|--------------|-------------|
| Polynomial Regression (deg=2) | **0.9983** | ± 0.0006 |
| Random Forest Regressor | 0.9953 | ± 0.0021 |
| Linear Regression | 0.9927 | ± 0.0016 |
| Decision Tree Regressor | 0.9917 | ± 0.0035 |

Тест лучшей модели: **R² = 0.9964, RMSE = 0.81, MAE = 0.60**.

**Классификация** (`student_pass.csv`, 62 строки, 4 признака):

| Модель | CV F1 | Test Accuracy | Test F1 |
|--------|-------|---------------|---------|
| Logistic Regression | **1.0000** | 0.9231 | 0.9091 |
| Decision Tree Classifier | 1.0000 | — | — |
| Random Forest Classifier | 0.9818 | — | — |

**Сходимость собственной математики:** Normal Equation и Gradient Descent дают
RMSE/R² идентичные sklearn, максимальное расхождение прогнозов — `0.00e+00`.

**Формула модели:** `test_score = 7.0454 · study_hours + 40.2404`
(каждый дополнительный час учёбы ≈ +7.05 баллов).

## Как это работает (кратко)

```text
CSV → анализ структуры → предобработка (Pipeline) → определение типа задачи
    → обучение N моделей × k-fold CV → сравнение средних показателей
    → выбор лучшей → оценка на тесте → сохранение → прогноз
```

Подробно (формулы, метрики, схемы) — раздел **03** дашборда и `SCIENTIFIC_PAPER.md`.
