1 · Загрузка

CSV читается через pandas. Проверяются размер, пустые файлы, кодировка UTF-8/BOM.

2 · Анализ структуры

Число строк и столбцов, типы данных, пропуски в процентах, уникальные значения, статистика min/max/mean/σ.

3 · Предобработка

Пропуски: медиана (числа) и мода (категории). One-hot кодирование категорий. StandardScaler для чисел. Всё внутри Pipeline — утечки данных исключены.

4 · Определение типа задачи

Целевая переменная непрерывная → регрессия; мало уникальных значений / 0-1 / текст → классификация. Можно переопределить вручную.

5 · Обучение с кросс-валидацией

Каждая модель обучается k раз на разных подвыборках. Среднее значение и стандартное отклонение — оценка устойчивости.

6 · Сравнение и выбор

Побеждает модель с максимальным средним CV-показателем (R² для регрессии, F1/Accuracy для классификации).

7 · Финальная оценка

Лучшая модель проверяется на отложенной тестовой выборке (20% данных, которые она никогда не видела).

8 · Сохранение и прогноз

Пайплайн (предобработка + модель) сохраняется в models/best_model.pkl — прогноз по new данным в один вызов.

03.2 · Кросс-валидация k-fold

Схема разбиения (k = 5)

Данные делятся на 5 частей. Проход 1–5: каждый раз другая часть служит тестом, остальные — обучающей выборкой. Итог — среднее по 5 оценкам и σ (насколько результат стабилен).

03.3 · Математический аппарат
Линейная регрессия
y = w·x + b
Функция потерь (метод наименьших квадратов)
L(w, b) = Σi (yi − (w·xi + b))² → min
Normal Equation (аналитическое решение)
w* = (XTX)−1 XT y
Градиентный спуск
wnew = w − α · ∂L/∂w
Полиномиальная регрессия (степень 2)
y = w1x + w2x² + b
Логистическая регрессия
P(y=1|x) = 1 / (1 + e−(wTx + b))
Коэффициент детерминации
R² = 1 − Σ(yi − ŷi)² / Σ(yi − ȳ)²
F1-score
F1 = 2 · Precision · Recall / (Precision + Recall)
03.4 · Метрики — что означают

R²

Какую долю дисперсии объясняет модель. 1.0 — идеал, 0.0 — как среднее.

MAE

Средняя абсолютная ошибка в единицах цели. Прямой «разброс» прогноза.

RMSE

Корень из MSE — штрафует большие ошибки сильнее, единицы те же, что у цели.

Accuracy

Доля правильных ответов классификатора из всех.

Precision

Из предсказанных «положительных» — сколько действительно положительных.

Recall

Из реальных «положительных» — сколько модель успела найти.

03.6 · Альтернативная реализация математики

Собственная линейная регрессия src/custom_linear.py

Реализована с нуля на NumPy двумя способами: аналитически (Normal Equation) и итеративно (градиентный спуск со стандартизацией признаков). Результаты сравниваются с эталоном sklearn — расхождение проверяется на каждом прогоне (раздел 01.4).

04.1 · Как запустить
# Windows — один клик: сервер + дашборд в браузере
start.bat

# Linux / macOS / вручную
pip install -r requirements.txt
python start.py          # поднимает http://localhost:5000

# интерактивное CLI-меню (опционально)
python main.py

# автотесты всего конвейера
python test_run.py
04.2 · Использование как Python-библиотеки
from src.pipeline import run_training, predict

# 1. обучить все модели и выбрать лучшую
result = run_training(dataset="study_scores.csv",
                      cv_folds=5, test_size=0.2)
print(result["best_model"], result["best_score"])

# 2. спросить прогноз у сохранённой модели
print(predict({"study_hours": 7.0}))
# {'prediction': 89.6, 'model': 'Polynomial Regression (degree=2)', ...}
04.3 · Использование через HTTP API
# список датасетов
curl http://localhost:5000/api/datasets

# описание датасета
curl "http://localhost:5000/api/describe?dataset=study_scores.csv"

# запуск тренировки (поток событий SSE)
curl -N -X POST http://localhost:5000/api/train \
     -H "Content-Type: application/json" \
     -d '{"dataset":"study_scores.csv","cv_folds":5,"test_size":0.2}'

# статистика всех тренировок
curl http://localhost:5000/api/stats

# прогноз
curl -X POST http://localhost:5000/api/predict \
     -H "Content-Type: application/json" \
     -d '{"values":{"study_hours":7.0}}'
04.4 · Решённые задачи (фактические результаты)

Задача 1 · Регрессия

  • Данные: study_scores.csv — часы учёбы → оценка
  • 62 строки, 1 признак, без пропусков
  • 4 модели × 5-fold кросс-валидация
Победа: Polynomial Regression (deg=2)
CV R² = 0.9983 · тест R² = 0.9964 · RMSE = 0.81

Задача 2 · Классификация

  • Данные: student_pass.csv — 4 признака → сдал/не сдал
  • 62 строки, бинарная цель pass (0/1)
  • 3 модели × 5-fold, scoring = F1
Победа: Logistic Regression
Accuracy = 92.3% · Precision = 100% · F1 = 0.909

Задача 3 · Сходимость математики

  • Собственная LR (Normal Equation) на NumPy
  • Сравнение с эталоном sklearn на тех же данных
  • Проверка максимума |разности| прогнозов
Макс. расхождение = 0.000000
Формула: score = 7.0454·hours + 40.2404

Задача 4 · Устойчивость к разбиению

  • Доли train/test: 70/30, 80/20, 90/10
  • Полный перебор моделей на каждой
  • Проверка: не «повезло» ли с разбиением
Полиномиальная регрессия лучшая на всех трёх пропорциях

Задача 5 · Влияние объёма данных

  • Обучение на 24 vs 49 примерах
  • Сравнение прироста качества по моделям
  • Кривая обучения: 10 % → 100 % данных
Decision Tree +0.0081 · Random Forest +0.0032 · линейная регрессия уже у предела

Задача 6 · Масштабирование (сессия ≥ 40 мин)

  • Синтетические датасеты 2 000–20 000 строк
  • Перебор гиперпараметров RandomForest
  • Проверка устойчивости к random_state

04.5 · Рекомендованный порядок работы для научной части

Практическая часть

  1. Запустить start.bat — откроется дашборд.
  2. В разделе «Тренировка» прогнать оба датасета при разных k и долях теста.
  3. Загрузить свой CSV и повторить тренировку.
  4. Снять все графики 01–07 и таблицы в отчёт.
  5. Запустить python extended_training.py — сессия ≥ 40 минут (раздел «Статистика» показывает её статус в реальном времени).
